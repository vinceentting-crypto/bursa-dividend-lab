免费自动读取股息 EXPERIMENTAL · V1.7

无需付费 API Key

优先尝试免费 Yahoo Finance 历史股息 ↗。即时查询通过公开的 AllOrigins 代理读取 Yahoo 非官方数据；可能因接口限流、网络或代理不稳定而失败。代理只会收到股票代码或搜索词，不会发送你的买入股数、价格或交易记录。

尚未联网。点「免费读取」尝试自动导入该股票的历史除息日和每股金额。

免费定时数据 · GitHub Pages

稳定版需要一次部署

完成 GitHub Pages 部署后，本页会自动读取公开缓存；GitHub Actions 会每日分批抓取股票，逐步扩充覆盖范围。首次部署并不代表全市场所有股息立即齐全。股票买卖记录只保留在当前浏览器，不会上传到公开仓库。 Yahoo 数据只含除息日/金额时，派发日标记待核实。

GitHub Pages 设置 ↗

特别说明：Yahoo 免费历史数据未必包含公告派发日、DRP、企业行动，也未必包含未来尚未除息的项目。股息年化预测是参考历史，而不是公司保证的金额；实时读取成功与否以页面提示为准。

计算说明

让结果可验证
派息资格：买入日期必须早于除息日；补仓或卖出也按交易日期计算持股数。应得股息 = 除息日前持股数量 × 公告每股股息。已到派发日仅指公告付款日期已过，并不能证明券商实际转账。
未来预测：从当前剩余持有股数与成本出发，按你设定的年度股息和增长率模拟，不把尚未公告的未来派息日期当成确定事实。卖出时按 FIFO 计算剩余股票成本；不含税务调整、DRP 股息再投资及股价波动。
Maybank 及 HIBISCS 资料为 2026-10-15 已核实静态快照（覆盖 2024–2026），不会自动联网更新；买入时间早于 2024 年时只能计算当前收录范围。股息为税前/再投资调整前的公告总额。其他股票可联网读取或导入 CSV，派付日期缺失时系统不推测。2026-10-22 的股息允许选择部分 DRP，实收现金应以券商账单为准。
